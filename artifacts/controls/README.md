# Control artifacts

This directory contains retained control-generation evidence. Generated Python
is untrusted data and must not be executed directly on a host system.

## Full StarCoder2 stock control

`stock-evalplus/` contains 164 greedy HumanEval completions generated by the
unmodified EvalPlus 0.3.1 Hugging Face path for the pinned StarCoder2-3B
revision. The condition matches the primary run: BF16, batch size one, base
prompt, eager attention, and 512 new tokens. The `stock-vs-optimized-*.json`
files compare every task with the retained primary artifacts without executing
model output.

The full stock and optimized files differ on three raw tasks (32, 38, and 50)
and two sanitized tasks (38 and 50). Hardened evaluation output is added only
after execution through the repository's network-isolated container path.

## Five-model equivalence control

`two-task-equivalence/stock/` contains fresh unmodified-EvalPlus outputs for
HumanEval/0 and HumanEval/1 from all five pinned models. Both raw and sanitized
records are byte-identical to the first two retained primary records for every
model. The hashes and condition metadata are recorded in
`protocol/all_models_stock_equivalence.json`.
